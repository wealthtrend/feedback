# Wealthtrend feedback

Public bug reports and ideas for [Wealthtrend](https://github.com/wealthtrend). The app's code is private; this repository only holds issues.

**Found a bug?** [Report it here](../../issues/new?template=bug.yml). The quickest way is the **Report a bug** link at the bottom of the app, which fills in your version for you.

**Have an idea?** [Suggest a feature](../../issues/new?template=feature.yml).

> ⚠️ Everything posted here is public. Please don't include real amounts, account numbers, names or screenshots of your own finances.
